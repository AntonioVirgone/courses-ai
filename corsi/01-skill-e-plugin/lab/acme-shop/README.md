# acme-shop

Progetto di esempio per il laboratorio del corso 01. È un negozio online immaginario: non si compila e non va eseguito, serve solo come repo su cui provare le skill.

Le aree del progetto, che sono anche gli scope dei commit:

| Scope | Area |
|-------|------|
| `api` | backend |
| `web` | sito |
| `mobile` | app |
| `core` | regole di business condivise (`packages/core`) |
| `types` | tipi condivisi |

In questa copia esiste solo `packages/core`: basta per fare commit veri e per provare le skill.

- Il glossario del dominio è in [CONTEXT.md](CONTEXT.md).
- Le decisioni sono in [docs/adr/](docs/adr/).
